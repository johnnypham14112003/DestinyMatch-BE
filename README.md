# DestinyMatch - Web APIs

## About

This is a Restful API web app, a clone version of source code using 3 layers structure in ASP .Net Core Web API.
Objective: Create opportunities for students to connect with each other and make friends, date

## Tech Using

- Asp .NET Core Web API
- Entity Framework
- Dependency Injection
- Microsoft SQL Server
- Google Auth APIs

## Features:

### Guest:
- Register for an account
- View homepage, service packages, policies, application information...

### User:
- Login
- Edit personal account information (required school name, major)
- Search & Filter
- View other people's account information
- Match, See who is paired with you
- Live chat (limited if not purchasing a package)
- Premium service package to see more

### Moderator:
- Manage Feedback & Report, Verify student card
- Manage User account

### Admin:
- Manage and authorize accounts
- Manage application content
- View revenue, summary
